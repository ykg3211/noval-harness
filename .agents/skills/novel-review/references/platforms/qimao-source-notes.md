# 七猫小说审稿要求与自审参考（临时整理）

整理日期：2026-10-10
用途：为小说创作 Harness 的审稿节点设计提供参考。

## 适用范围与证据边界

- 签约质量评估与内容发布审核是不同环节，内容合规不等于一定可以签约。
- 目前未找到七猫公开的统一签约评分表、各维度权重或必过稿分数。
- 下文区分官方明确规则、官方创作指导、整理者自审建议和待核实的特定征文要求。
- 具体投稿须以当时官方后台、目标征文公告、编辑反馈及签署合同为准。

## 一、常规投稿材料和审稿流程

来源：[七猫官方投稿与福利说明](https://www.qimao.com/fuli/)。本次读取时页面标题仍标注2025年。

### 投稿材料

- 编辑投稿：开篇2万字正文、大纲、投稿申请表。
- 直接注册发文：发表满2万字后申请签约评估。
- 选择一位编辑投稿；收到审稿意见前，不要将同一稿件投给其他网站。
- 特定征文可能设有不同字数和材料要求，2万字不是所有通道的统一门槛。

### 流程与时间

编辑初审 → 审稿委员会复审 → 总编终审 → 反馈结果。

- 邮箱或编辑QQ投稿：页面标注1至3个工作日，节假日顺延。
- 直接发文申请签约：页面标注3至7个工作日，节假日顺延。
- 以上为页面说明，不作具体稿件审核时限保证。

## 二、官方创作指导

来源：[七猫官方新手指南](https://www.qimao.com/gonggao/62208650921d7d382c75de46/)，发布于2022-03-03。

- 研究同题材排行榜作品，分析冲突、矛盾和情节爽点。
- 关注题材和读者市场的变化。
- 重视作品大纲，以及书名和简介的打磨。
- 保持稳定更新，留意读者对情节和文字问题的反馈。

证据边界：这是历史创作指导，不是当前完整审核细则，也不构成签约承诺。

## 三、故事质量自审维度（整理者建议，非官方评分表）

| 维度 | 自审问题 |
| --- | --- |
| 题材与受众 | 面向哪类读者？主要吸引力是否清楚？ |
| 开篇吸引力 | 主角面临什么问题？读者为什么继续阅读？ |
| 主线与目标 | 主角想得到什么？剧情是否推进了目标？ |
| 冲突与情绪 | 阻力是否具体？情绪铺垫是否得到兑现？ |
| 人物 | 主角是否主动选择？配角是否拥有合理动机？ |
| 可读性 | 行文是否清楚？是否存在过多设定说明、重复和无效情节？ |
| 大纲可持续性 | 开篇之后是否有升级、转折和阶段性结果？ |
| 逻辑一致性 | 动机、能力、时间线和角色信息来源是否自洽？ |

未找到官方依据支持以下说法作为统一硬规则：前三章必须打脸、每章必须一个爽点、对话必须达到固定比例。

## 四、原创与内容发布规则

来源：[原创作品登载规则和服务约定](https://zhushou.qimao.com/writer-rules/68466f6ae4a81e7ec312f8cd/)。以下为摘要，不代替原文。

### 原创与权利

- 作品须为本人自主、独立创作，并具有必要的权利或授权。
- 不得抄袭、剽窃、歪曲或篡改他人创作，不得侵害第三方合法权益。
- 约定还要求与作者本人享有著作权的其他作品不构成实质性相似。
- 平台可以要求提供作品权利证明。
- 官方投稿政策明确禁止工作室投稿，并将同一本书不止一个作者列为工作室定义。

### 禁发内容类别

平台约定列有以下禁止内容类别：

- 危害国家安全、国家统一、国家荣誉和利益等内容。
- 煽动民族仇恨、民族歧视，破坏民族团结等内容。
- 破坏国家宗教政策、宣扬邪教和愚昧迷信等内容。
- 低俗、危害社会公德和中华民族优秀文化传统等内容。
- 散布谣言，扰乱社会秩序、破坏社会稳定等内容。
- 淫秽色情、赌博、暴力、凶杀、恐怖或者教唆犯罪等内容。
- 影射、歪曲、诋毁公众人物、时事政策、国家政治军事形象等内容。
- 侮辱、诽谤、抄袭、侵犯第三方合法权利及其他法律法规禁止的内容。

具体情节须结合上下文和平台审核判断，不能把上述类别简单实现为关键词命中即违规。

## 五、连载及福利资格

来源：[七猫官方福利规则](https://www.qimao.com/fuli/)。

- 福利条件涉及无断更、灌水、抄袭等不良记录。
- 全勤涉及更新字数、有效更新、数据达标及其他合同类型对应条件。
- 这些要求应与首次签约的故事质量评估分开，不宜将全勤日更要求直接视作所有合同统一的签约门槛。

## 六、AI内容：特定征文要求与待核实事项

来源：[橙瓜刊载的七猫“崛起于微末，腾跃于云巅”征文规则](https://news.chenggua.com/detail/36697.html)。

该页面标注活动期为2026-07-10至2027-06-30，列出：

- 正文禁止使用AI生成内容。
- 要求行文流畅、主线清晰、有明确剧情目标，剧情不老套、人设不呆板。
- 该活动有6000字正文加大纲的投稿通道。
- 原创、首发、此前公开发表情况及获奖情况有额外限制。

证据边界：以上来自第三方刊载的特定征文规则，尚未核实官方原帖。不能据此断言七猫所有通道一律禁止全部AI辅助。

尚待向目标通道核实：

- AI用于大纲分析、审稿、校对、润色及正文生成时，分别有哪些限制？
- 是否需要声明，如何声明？
- 目标合同或活动是否有额外限制？

未找到可靠官方依据支持“AI率低于某个百分比即可过审”，不应把商业检测器分数作为平台通过标准。

## 七、Harness审稿节点设计建议（非七猫官方要求）

1. 投稿材料检查：校验字数、正文、大纲、申请表与目标通道材料要求。
2. 原创与内容规则检查：结合上下文提示疑点，并检查来源、权利及活动适用范围。
3. 故事质量审查：按开篇、主线、人物、情绪、可读性和持续发展能力输出建议。

每条审稿意见建议包含：原文位置、原文证据、问题类型、严重程度、依据来源、适用范围、修改建议，以及是否需要人工确认。

程序可以检查材料完整性，模型可以辅助发现叙事问题；均不能代替七猫编辑的签约决定，也不应以模型评分声称保证过稿。
