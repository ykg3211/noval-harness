# 人物召回与场景推演

## 场景快照与临时状态

为场景记录故事时间、地点、在场者、环境约束及实际发生的事。作者知道的真相与各人的可感知信息分开。

章内临时状态记录已裁定事件、位置、伤势、资源、关系变化和各人的新知识，注明事件 ID、发生及获知时间。人物的新知识只能来自观察、交流或有依据的推断，不能自动共享给所有在场者。

续接草稿的变化也可进入临时状态，但标注 draft 来源。重推场景时从该场景之前的快照恢复，废弃原结果及依赖它的后续状态，保留推演记录，不让被否决分支混入新一轮。

## 召回步骤

1. 必读人物 profile、goals，提取价值排序、底线、行为依据和当前欲望。
2. 按场景时间从 state、relationships、knowledge 和事件重建当时状态，叠加已裁定的章内变化；不能将最新状态用于更早时间。
3. 通过 memories/index 和 extensions 召回与场景人物、地点、物品、目标和心理触发点相关的记忆；遵守该小说 memory-types 的扩展约定。
4. 过滤尚未发生或人物尚未获知的信息。保留人物误解及确信程度，不用作者真相纠正人物视角。
5. 保存精简的上下文包，逐条标注依据 ID 与来源；没有依据的关键状态标为未知，不为制造冲突擅自编造旧经历。

## 子 Agent 输入模板

将下面指令与过滤后的具体内容作为人物 Sub Agent 的完整任务，使用独立会话。不得让子 Agent 打开小说完整目录；文件访问仅限本次上下文包及明确列出的、属于该人物的过滤材料。优先直接提供内容，避免链接把它引向作者档案。

```text
你负责推演【人物 ID / 名称】在当前场景下的反应。
你的创作依据仅限下面提供的材料。不要搜索工程、读取其他档案、调用其他 Agent 或修改文件。
不要替其他人物决定反应；他人的内心和未提供的真相均未知。
尝试行动不等于行动成功，结果由主 Agent 根据世界约束裁定。
性格是倾向，结合具体目标、压力和代价判断，不机械照搬标签。

【故事时间及可感知场景】
【人格、价值排序、底线】
【当前目标、身体、情绪与资源】
【对相关人物的主观认识】
【相关记忆、已知信息、误解与不确定性，含依据 ID】
【物理或制度约束：仅限人物知道的部分】

输出：
1. 局势理解：认为发生了什么，哪里不确定。
2. 情绪与动机：哪些目标或经历被触发。
3. 决策：此刻准备做什么及原因。
4. 外在表现：可观察的动作、表情与可能说的话。
5. 内心活动：仅供写作参考，不自动被其他人物获知。
6. 改变决定的条件：哪些新信息或行为会改变选择。
7. 依据：引用所给材料中的 ID；无依据的推测明确标注。
```

不要把“本章需要他答应合作”等作者目标放进输入。人物底线确实阻碍目标时，由主 Agent 调整情节条件或承认失败，不能篡改人物输出来达成预设结果。

## 编排和裁定

- 同轮有独立决策的人物可并行调用，默认每个人物每轮新建独立 Sub Agent。下一轮重新提供经整理的个人上下文，持续性由档案和临时状态保证。
- 主 Agent 按行动顺序、空间、能力和世界规则判定成功、失败及代价；未被感知的动作不进入其他人物下一轮输入。
- 一轮不能覆盖整场持续对话。每当新信息足以改变决策，进入下一轮；简单连续动作可以合并。
- 决策已稳定、场景目标完成或出现新的场景条件时结束该节点，不为验证同一选择无限重复调用。
- 发现 Sub Agent 使用未提供知识或擅自保证结果时，纠正输入边界并重新推演该部分；记录实质偏离及处理。

## 推演记录

每次写作执行创建唯一 `runs/<chapter>-<scene>-<run>/`，保留 context.md、inputs/<character>-rNN.md、reactions/<character>-rNN.md、resolution.md、review.md。上下文中保留材料来源，输入人物时不暴露作者专用材料。

resolution 区分尝试行动、实际结果、各人观察及新认知、章内状态变更和被废弃分支。记录足以解释因果即可，不要求输出隐藏推理过程。
