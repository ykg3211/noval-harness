# 续写默认编写风格

本规范将用户认可的风格讨论固化为续写默认准则，服务章节计划、正文与内部自检。核心为：**语言轻松易读、主线有悬念、人物选择有代价。** 用户明确要求优先；已有作品的视角、人物声线和基调是续接基线。不因采用本规范追溯修改旧章，不把市场趋势当成销量保证。

## 三个核心如何落在正文

### 语言轻松易读

- 让读者容易辨认谁在何处、想做什么、受到什么阻碍。以具体动作、对话与感官细节呈现；背景、规则和术语在影响当前行动时交代，避免连续设定说明。
- 句子和段落随动作、思考与情绪自然变化。紧张时可以短促，观察与余韵允许舒展；不规定字数、短句比例或一行一句。
- 人物对话体现各自的身份、关系与说话目的，潜台词来自隐瞒、试探、回避或争取。避免全员同样吐槽，避免人物替作者向彼此讲解双方早已知道的常识。
- 情绪优先通过选择、动作、停顿和具体感受表达。已经呈现的情绪和意义不再反复总结；必要的心理叙述与环境描写仍可保留。
- “轻松”是阅读负担低，不是持续逗笑。悲伤、危险、庄重场景保持应有分量；不靠网络热梗、夸张比喻或密集感叹制造虚假的活泼。

### 主线有悬念

- 从当前处境延续读者在意的具体问题：事情为何异常、目标如何实现、关系如何变化、选择会造成什么后果。悬念可以来自情感与命运，不要求改成悬疑题材。
- 推进时提供新证据、排除解释、改变局面或给出阶段答案。先兑现或深化已有问题，再决定是否开新问题；不用陌生名词和不断升级的秘密替代进展。
- 反转必须由既有规则、人物动机及已出现的线索支撑。读者回看时能理解；视角人物已知的信息，不为制造惊讶而无故避开。
- 场景和章末落在有意义的变化上：决定、结果、关系改变、下一步行动或情绪余韵均可。没有每章反转、每场危险、固定断章的要求。

### 人物选择有代价

- 重要决定来自人物的欲望、底线、有限信息和资源限制。让可行路径之间存在取舍，例如时间、机会、信任、责任、安全或价值冲突。
- 让选择改变后续条件：成功可能带来责任或暴露，失败可能迫使调整策略；关系中的承诺与伤害也应留下影响，不能下一场自动归零。
- 代价不等于强制受伤、死人或压抑主角。代价可在此前付出或后续显现，日常小事也不必全部升级成道德难题。
- 对手和重要配角有自身目标与可行策略，允许人物作出不同于作者预期的可信选择。不能靠降智、临时规则或强行牺牲实现预设效果。

## 按场景选择辅助手法

这些手法不互斥，也不构成每章必填清单。根据作品承诺和当前场景选择必要项。

| 手法 | 适合的用途 | 执行边界 |
| --- | --- | --- |
| 轻松吐槽、反套路 | 用性格反差、现实诉求、误会或预期偏差制造趣味 | 笑点来自处境和人物，笑过之后仍能推进关系或行动；不为反套路破坏因果，不反复消费同一笑点 |
| 规则博弈、智斗 | 用有限信息、资源和规则组织解题、试探与竞争 | 提前呈现解法需要的条件，结果伴随风险或取舍；对手合理，不靠事后新增规则显得主角聪明 |
| 生活流、轻喜剧、治愈 | 用工作、吃饭、相处、旅途等建立真实感和陪伴感 | 日常细节应使人物、关系或生活状态发生可感知变化；允许安静与停留，不把温暖写成空泛说教 |
| 强情绪、快节奏、场景化 | 在关键冲突或短篇结构中迅速建立目标、阻碍与情感风险 | 尽早进入具体事件，但保留必要动机与因果；情绪有积累和释放，不连环反转、不用危言耸听代替兑现 |
| 群像、人物驱动 | 用不同目标与立场使冲突自然形成，扩大关系与世界的厚度 | 重要配角有自己的选择，出场和视角切换服务当前故事；遵守有限视角，不为展示群像打断主线或遍历所有人内心 |

## 写作流程中的执行

- 读前序正文时识别实际声线、叙述距离、幽默方式、信息密度和节奏，结合用户要求确定本章延续方式，不重新开展风格问卷。
- 在 `plan.md` 的既有阅读体验与场景计划中简记风格落点，不建立第二套悬念或回报索引。是否使用辅助手法由主 Agent 判断，人物推演仍只接收个人可知的处境、记忆和约束。
- 草稿完成后对照实际正文检查。出现问题时修正文，不以“风格：轻松、悬疑、有代价”等标签替代执行；只将实质问题与修正写入既有 `review.md`。

## 交稿前正文自检

1. 当前目标和阻碍是否容易理解？是否存在可嵌入行动的说明堆积、同义情绪总结或无用术语？
2. 对话能否区分人物？幽默是否符合此人的性格、关系和此刻处境？
3. 本章是否推进或回应了读者在意的问题，或承接了上一章的结果？是否只添谜语、没有有效变化？
4. 关键解法与反转能否追溯到正文条件？人物与读者的信息边界是否成立？
5. 重要选择是否源于真实动机，其取舍或后果是否可感知？是否为追求刺激强加惩罚、降智或遗忘后果？
6. 节奏是否适合本章功能，是否给情绪与关系留下感受的空间？结尾是否自然，而非突然截断？
7. 是否延续原作声线，并遵守本轮用户的风格要求？是否把全部辅助手法机械堆进同一章？
