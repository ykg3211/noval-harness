# 共创对话指南

## 首轮

用户没有给出设想时，可从以下三点开始，用自然语言提问，接受自由回答：

1. 想写什么题材、氛围，最想让读者获得什么体验？
2. 有没有一个人物、画面或冲突，想作为故事起点？
3. 更想写短篇、完整长篇还是连载？暂时不确定也可以。

已有素材时，先复述你理解的一句话故事，只问缺失且会改变设计的问题。只有模糊感觉时，提供 2–3 个有具体人物、困境与代价的方向，不只列类型名称。

## 深化时按需选题

| 主题 | 要探索的设计问题 |
| --- | --- |
| 故事承诺 | 读者为什么翻页？悬念、情感、成长或探索由什么持续供给？ |
| 主角 | 想得到什么？真正需要什么？什么弱点使目标更难达到？ |
| 阻力 | 对手或环境为什么阻止主角？对方追求什么合理目标？ |
| 世界 | 哪条规则决定冲突？力量、制度或资源有什么限制和代价？ |
| 关系 | 人物互相需要什么、隐瞒什么、误解什么？什么会改变信任？ |
| 结构 | 哪些故事线并行？视角如何切换？关键转折带来什么后果？ |
| 成长 | 人物会改变哪种信念？改变要付出什么？也允许拒绝改变。 |
| 风格 | 叙述距离、视角、节奏、语言密度，哪些内容应避免？ |
| 长期维护 | 哪些记忆会反复影响选择？是否需要技能、誓约、身份等扩展类型？ |
| 回报偏好 | 最想看到能力被证明、被理解、解谜、建立秩序还是其他体验？不喜欢哪种人为压抑？ |
| 长线回收 | 哪个未来改变最值得回头看？早期可以自然出现什么？结局未定时有哪些兼容解释？ |

不要求每项都问完。用当前回答提出下一层设计，例如“若主角把安全感寄托在控制信息上，同伴隐瞒善意也会引发冲突”，再让用户调整。

读者体验应转化成可讨论的具体情节：不是只问“要不要爽”，而是比较“用专业能力解决被忽视的难题”和“公开推翻不公评价”两种不同的回报路径。伏笔要与当前行动结合，不单独堆一份秘密列表。

## 收敛标准

能说明开篇处境、主角追求、主要阻力、关系张力和发展方向，就可以建立第一版。篇幅、结局或章数仍可待定。用户不想提前决定结局时，记录可能的收束方向，不强迫选择。

- 已确定：用户明确选择，或沿用用户已有材料。
- 暂定：Agent 为推进第一版提出，用户允许先采用。
- 待定：未作选择；写明影响和可选方向。

对话示例：用户只说“悬疑，主角是失忆的修钟师”。下一轮应围绕记忆与案件的联系提出具体方向，如记忆被人为封存、时钟记录他人经历、主角曾参与案件，并询问偏好的现实或幻想程度；不要立即生成完整历史和结局。
