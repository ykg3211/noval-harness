# 阅读期待与回报

本规范供框架初始化与章节续写共用。这些是可调整的创作工具，不是强制套路、字数公式或效果保证。

## 先确定作品承诺

与用户讨论希望读者持续得到什么体验，选一个主要方向及少量辅助方向即可，不把下面所有类型全部装进一本书。

| 回报机制 | 前提与积累 | 兑现方式 | 可信性要求 |
| --- | --- | --- | --- |
| 能力与成长 | 明确难题，展示学习、训练或判断 | 原先做不到的事终于做到 | 成果能追溯到能力和代价 |
| 认可与尊严 | 人物有值得被看见的价值或受限处境 | 用行为改变评价、夺回选择权 | 评价者有自身利益，不统一震惊 |
| 智谋与掌控 | 信息、规则、资源对各方不对称 | 用已存在条件找到新解法 | 对手合理，解法不依赖临时规则 |
| 公正与清算 | 明确伤害、责任和读者在意的损失 | 行为承担后果，受害者获得修复 | 不是无限羞辱和不断追加恶行 |
| 关系与归属 | 建立共同经历、冲突与情感风险 | 理解、选择、信任、保护或分离 | 变化由行动支撑，不只靠告白 |
| 探索与认知 | 呈现具体异常与可理解的问题 | 答案重组旧信息，打开更深世界 | 给线索和阶段答案，不靠术语堆积 |
| 建设与收获 | 资源短缺，目标和分工清楚 | 生活、组织或系统切实改善 | 成果可感知，建设会改变关系与责任 |
| 幽默与反差 | 建立性格、情境和预期 | 合理偏差带来趣味，旧梗获得新含义 | 笑点不毁人物、不重复同一结构 |
| 坚持与救赎 | 有限处境中仍要作出选择 | 保住价值、修复伤害或接受代价 | 可悲可喜，不强迫大获全胜 |

## 初始化时设计什么

在 `reader-promise.md` 写：目标阅读体验、主辅机制、主角为何值得在意、开篇如何让体验可感知、作品差异、压抑和释放的偏好、读者容易疲劳的套路，以及哪些承诺是确定或暂定。

将核心回报倒推为：读者在意的缺口 → 人物目标 → 可信阻力 → 主动选择与积累 → 结果 → 结果带来的后果。压力可以来自难题、竞争、责任或情感风险，不必先羞辱主角。允许失败、牺牲和悲剧，但故事应对已建立的情感与主题期待作出回应。

在 `outline/payoffs.md` 记录稳定 ID（如 payoff-001）、关联阅读承诺、受益或受损人物、前置积累、阶段性进展、目标兑现条件与窗口、兑现代价及后果、与伏笔的关系、计划状态与实际正文证据。

分别考虑场景或章节的小进展、故事线或分卷的阶段回报、全书的核心兑现。窗口可用“身份被质疑后的首次公开行动”“本卷收束前”，无需写死每隔几章一个高潮。先确定关键因果和长线前置条件，其他路径保留弹性。

开篇用具体处境、行动和可理解的疑问示范核心体验；不要求首章解释整个世界，也不为了快而省掉人物为何在意。

## 剧情如何升级

升级可改变困难性质、利益牵涉、关系代价、规则理解和价值冲突，不只有敌人更强。让上一次成功改变局面，产生下一次选择的条件，形成因果链，避免每卷清空成长和关系后重复同一冲突。

对手也有目标、信息边界和可行策略；主角优势可能暴露、被应对或附带责任。保留反思、日常和情感余韵，给回报被感受的时间。

## 章节阶段怎么执行

先读作品承诺、待兑现回报和近章实际内容，再讨论本章让什么发生变化。结合本章位置选择铺垫、推进、兑现或余韵，不能要求每章同时完成全部功能。

`plan.md` 增加“本章阅读体验”：主要期待、对应 payoff ID（没有则不编造）、可见进展、压力与释放、计划回报和后果、章末继续阅读的理由。可用决定后的后果、关系改变、探索方向或安静的情绪收束，不必每章强行断在危险瞬间。

审查正文时回答：读者为什么在意？这一章具体改变了什么？结果是否来自人物选择和已有条件？是否回应了当前承诺？是否与近章重复？若本章只铺垫，是否仍有行动、信息或情感进展？

不要只写“很燃”“很爽”的标签，也不使用无依据的爽度分数。未有真实读者反馈时只能预测体验，不能声称读者必然兴奋或已经满意。

## 与人物推演的边界

阅读回报是主 Agent 的作者目标，不是人物命令。不把“该被打脸”“该牺牲”“该告白”交给人物 Sub Agent。通过处境和真实动机引出选择；推演不支持预期回报时，调整条件或采用更符合人物的回报路径。

若调整会放弃用户明确要求的关键情节，提出具体冲突与替代办法，不能借“人物自然反应”偷偷改掉要求。

## 长线维护

创作前关注长时间没有可见进展的核心承诺、被反复延迟的兑现和近章同质化。延迟时记录原因及下一次推进条件，先考虑兑现或深化现有线索，再增加新坑。故事线收束时检查承诺是否回应，哪些余项应明确保留或取消。

正文未定稿时，实际进展记录在本章临时状态和 changes.md；计划可更新，但不把预计回报登记为实际兑现。定稿后统一更新 payoff 的进展、来源和状态。
